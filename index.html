    audit-core

    A framework-agnostic accessibility audit engine. You point it at a DOM and get structured violations back, each with the failing selector, the reason and a suggested fix. Contrast can be checked with APCA or WCAG, and it runs in the browser or in CI.

    product · built on audit-core

    Contrastly

    Checks every color pair on a site against APCA and WCAG 2.x side by side, so you can see the cases where WCAG passes text that APCA says is hard to read. For each failing pair it suggests alternative colors.
